# 玩家控制功能开发总结

## 概述
本次开发将无名杀简化版从全自动流程改为玩家控制模式，实现了完整的玩家交互系统。

## 已完成功能

### 1. 玩家交互状态管理
- **文件**: `src/composables/usePlayerControl.ts`
- **功能**:
  - 管理玩家操作状态（空闲、选择卡牌、选择目标、选择技能、确认）
  - 处理卡牌选择逻辑
  - 处理目标选择逻辑
  - 处理技能选择逻辑
  - 提供操作确认和取消功能

### 2. 游戏核心逻辑更新
- **文件**: `src/core/game.ts`
- **更新**:
  - 添加 `waitingForPlayer` 状态标志
  - 修改出牌阶段逻辑，等待玩家操作
  - 添加 `endPlayPhase()` 方法，允许玩家主动结束出牌阶段

### 3. 类型定义扩展
- **文件**: `src/types/index.ts`
- **新增类型**:
  - `PlayerControlState`: 玩家控制状态枚举
  - `PlayerControl`: 玩家控制信息接口
  - 更新 `GameState` 接口，添加玩家控制相关字段

### 4. UI组件更新

#### GameArena.vue
- 集成玩家控制管理
- 添加操作确认/取消UI
- 添加"结束出牌"按钮
- 显示当前选择状态（卡牌、技能、目标）
- 集成AI控制逻辑

#### HandCards.vue
- 接收 `canUseCard` 函数作为prop
- 根据玩家控制状态判断卡牌是否可用
- 支持外部控制卡牌可用性

#### SkillButton.vue
- 接收 `canUseSkill` 函数作为prop
- 根据玩家控制状态判断技能是否可用
- 支持外部控制技能可用性

### 5. AI控制系统
- **文件**: `src/composables/useAIControl.ts`
- **功能**:
  - 自动执行出牌阶段
  - 智能选择卡牌和目标
  - 简单的AI策略：
    - 优先使用桃回复体力
    - 使用杀攻击敌人
    - 使用锦囊牌
    - 装备装备牌
    - 使用主动技能

## 使用说明

### 玩家控制流程

#### 1. 出牌阶段
当游戏进入出牌阶段时，当前回合的玩家可以：
- 点击手牌中的卡牌进行选择
- 点击技能按钮使用技能
- 点击"结束出牌"按钮结束出牌阶段

#### 2. 使用卡牌
1. 点击手牌中的卡牌
2. 如果卡牌需要目标，点击其他玩家作为目标
3. 点击"确认"按钮使用卡牌
4. 或点击"取消"按钮取消选择

#### 3. 使用技能
1. 点击技能按钮
2. 如果技能需要目标，点击其他玩家作为目标
3. 点击"确认"按钮使用技能
4. 或点击"取消"按钮取消选择

#### 4. 结束出牌
点击右下角的"结束出牌"按钮，结束当前出牌阶段，进入弃牌阶段。

### AI控制

默认情况下，所有玩家都是人类玩家。如果需要将某个玩家设置为AI，可以在代码中修改：

```typescript
// 在 GameArena.vue 中
if (playerControl.value) {
  // 设置为AI玩家
  playerControl.value.setPlayerType(false)
}
```

AI玩家会在出牌阶段自动执行操作，包括：
- 使用桃回复体力
- 使用杀攻击敌人
- 使用锦囊牌
- 装备装备牌
- 使用主动技能
