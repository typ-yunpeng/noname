# 无名杀静态界面展示

这是一个从无名杀项目中提取的独立静态界面展示页面，基于对原始代码的深入分析创建，可以直接在浏览器中运行。

## 文件说明

- `index.html` - 主HTML文件，包含游戏界面的DOM结构（基于 `arena()` 方法分析）
- `styles.css` - 样式文件，包含所有界面的CSS样式
- `script.js` - JavaScript文件，包含交互逻辑和事件绑定
- `start.bat` - Windows启动脚本
- `start.sh` - Linux/Mac启动脚本
- `README.md` - 本说明文档

## 功能特性

### 界面元素（基于原始代码结构）
- ✅ 主窗口容器 (`#window`)
- ✅ 状态背景 (`#statusbg`)
- ✅ 系统控制区域 (`#system`)
  - 设置按钮
  - 暂停/继续按钮
  - 自动按钮
  - 无懈可击按钮
- ✅ 游戏信息区域 (`#time`)
  - 牌堆数量显示
  - 游戏时间显示
- ✅ 历史记录栏 (`#historybar`)
- ✅ 游戏竞技场 (`#arena`)
  - 游戏日志 (`#arenalog`)
  - 回合菜单 (`#roundmenu`)
  - 玩家卡片（4个示例玩家）
    - 头像 (`.avatar`)
    - 姓名 (`.name`)
    - 血量 (`.hp`)
    - 装备 (`.equip`)
    - 判定区 (`.judge`)
    - 手牌 (`.handcards`)
    - 手牌数量 (`.count`)
- ✅ 背景音乐元素

### 交互功能
- ✅ 点击玩家卡片选中
- ✅ 点击手牌选中
- ✅ 控制按钮功能（设置、暂停、自动、无懈可击）
- ✅ 回合菜单点击
- ✅ 游戏时间计时
- ✅ 牌堆数量更新
- ✅ 游戏日志记录
- ✅ 历史记录显示
- ✅ 工具提示显示
- ✅ 键盘快捷键支持

### 快捷键
- `ESC` - 清除所有选中状态
- `空格` - 暂停/继续
- `A` - 切换自动模式
- `W` - 切换无懈可击
- `Enter` - 出牌（需要先选中手牌）

## 使用方法

### 方法1：直接打开
直接在浏览器中打开 `index.html` 文件即可。

### 方法2：使用启动脚本
- **Windows**: 双击 `start.bat`
- **Linux/Mac**: 运行 `bash start.sh`

### 方法3：手动启动服务器
```bash
# 使用 Python
python -m http.server 8000

# 使用 Node.js
npx http-server -p 8080

# 使用 PHP
php -S localhost:8000
```

然后在浏览器中访问对应地址：
- http://localhost:8000
- http://localhost:8080

1. **顶部控制栏** - 包含设置、暂停、自动、无懈可击按钮

### JavaScript逻辑

## 自定义修改

### 修改玩家信息
在 `index.html` 中找到 `.player` 元素，修改 `.name` 的内容即可更改玩家姓名。

### 修改血量
在 `index.html` 中找到 `.hp` 元素，添加或删除 `div` 元素来调整血量显示。

### 修改手牌数量
在 `index.html` 中找到 `.handcards` 元素，添加或删除 `.card` 元素来调整手牌数量。

### 修改样式
在 `styles.css` 中可以自定义颜色、大小、布局等样式。

### 修改交互逻辑
在 `script.js` 中可以修改点击事件、动画效果等交互逻辑。
