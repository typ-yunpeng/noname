清除dm_caocao皮肤配置

说明：

此页面用于清除之前保存的dm_caocao皮肤配置，恢复默认皮肤。

清除后，皮肤切换将只在当前游戏会话中有效，不会保存到配置文件。

手动清除方法：

如果按钮无法使用，可以在游戏页面的浏览器控制台中执行以下代码：

// 清除dm_caocao的皮肤配置
const configPrefix = 'noname_';
const skinConfig = localStorage.getItem(configPrefix + 'skin');
if (skinConfig) {
    const skinData = JSON.parse(skinConfig);
    delete skinData['dm_caocao'];
    localStorage.setItem(configPrefix + 'skin', JSON.stringify(skinData));
    console.log('dm_caocao皮肤配置已清除');
}
